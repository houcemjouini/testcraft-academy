SeleniumLibrary: Web UI Testing Basics

⏱ 11 min 📖 Module 3 of 8 🎯 Intermediate

In this lesson, you'll learn how to use SeleniumLibrary with Robot Framework to automate browser interactions. We'll cover opening browsers, navigating pages, interacting with elements, and asserting page state.

By the end of this lesson you'll be able to write complete end-to-end UI tests using RF and Selenium, run them headlessly in CI/CD, and generate beautiful HTML reports automatically.

SeleniumLibrary Browser automation Web UI testing Headless Chrome RF reports

Robot Framework test suite using SeleniumLibrary:

*** Settings *** Library SeleniumLibrary Library Collections *** Variables *** ${URL} https://your-app.com ${BROWSER} headlesschrome ${TIMEOUT} 10s *** Test Cases *** User Can Log In Successfully Open Browser ${URL} ${BROWSER} Set Selenium Timeout ${TIMEOUT} Input Text id:email user@example.com Input Password id:password secret123 Click Button xpath://button[@type='submit'] Wait Until Page Contains Welcome, User Title Should Be Dashboard [Teardown] Close Browser *** Keywords *** Login With Credentials [Arguments] ${email} ${password} Input Text id:email ${email} Input Password id:password ${password} Click Button css:.btn-login

Run your tests:

# Run all tests robot tests/ # Run with tags robot --include smoke tests/ # Headless + custom output robot --outputdir reports/ --variable BROWSER:headlesschrome tests/
